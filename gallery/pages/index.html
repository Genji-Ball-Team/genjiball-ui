Genji Ball UI

Tokens, CSS, icons and gb- web components for genjiball.us and the host tool, from @genji-ball-team/ui. Every page loads the published build. Hover and focus are live: point at a control or press Tab.

Install

npm install @genji-ball-team/ui
import "@genji-ball-team/ui/base.css";
import "@genji-ball-team/ui/button.js";
